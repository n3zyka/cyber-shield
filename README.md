# 🛡 КіберЩит — кібербезпека простими словами

Освітній багатосторінковий сайт про кібербезпеку. Індивідуальне завдання з дисципліни «Вступ до фаху».

## Сторінки

| Сторінка | Зміст |
|---|---|
| `index.html` | Головна: статистика, тріада CIA, огляд розділів, професії в кібербезпеці |
| `threats.html` | Види загроз: шкідливе ПЗ, ransomware, DDoS, MITM, SQL-ін'єкції, XSS, zero-day |
| `passwords.html` | Хешування, сіль, методи злому, 2FA, passkeys + **перевірка пароля** і **генератор** |
| `phishing.html` | Соціальна інженерія, види фішингу, анатомія посилань + **вікторина** |
| `crypto.html` | Історія шифрів, AES, RSA, хеш-функції, HTTPS, постквантова криптографія + **шифр Цезаря** і **SHA-256** |
| `attacks.html` | Хронологія відомих атак (Морріс, Stuxnet, WannaCry, NotPetya, Київстар) з фільтрами |
| `protection.html` | Правила цифрової гігієни + **інтерактивний чек-лист** |
| `sources.html` | Список використаних джерел |

## Технології

HTML5, CSS3 (Grid, Flexbox, анімації), чистий JavaScript (Web Crypto API, Canvas, IntersectionObserver, localStorage). Без сторонніх бібліотек.

## Запуск

Відкрити `index.html` у браузері або перейти на сторінку GitHub Pages репозиторію.
