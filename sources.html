Про проєкт

Сайт «КіберЩит» створено як індивідуальне завдання з дисципліни «Вступ до фаху». Мета проєкту — у доступній формі пояснити основи кібербезпеки та показати, як знання з комп'ютерних наук (алгоритми, криптографія, мережі, бази даних) застосовуються для захисту інформації.

Технології: HTML5, CSS3 (Grid, Flexbox, анімації, змінні), JavaScript (Web Crypto API, IntersectionObserver, Canvas, localStorage). Сайт не використовує сторонніх бібліотек і розміщений на GitHub Pages.

Застереження

Інформація на сайті має освітній характер. Усі приклади атак наведено для того, щоб навчити розпізнавати та запобігати їм. Використання описаних методів проти чужих систем без дозволу є злочином (стаття 361 Кримінального кодексу України).
